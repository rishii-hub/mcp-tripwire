# mcp-tripwire

Safety testing and reliability CI for AI agents using MCP servers.

Tripwire is a transparent MCP proxy that discovers which of an agent's tools are
irreversible, generates adversarial pressure scenarios against them, and fails
your build when the agent takes a destructive action it should have refused.

**Status:** early development. Built for OOSC 4.0 (GDG IIIT Allahabad, 2026).
